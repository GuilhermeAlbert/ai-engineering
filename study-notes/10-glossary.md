# Glossary — Quick Reference

← [Back to overview](00-overview.md)

A one-stop, alphabetized reference to every key term covered across the modules, for fast review before a quiz, meeting, or capstone write-up. Each entry links to the module where it's explained with a full example.

| Term | One-line definition | Full explanation |
|---|---|---|
| **ADKAR** | Individual-level change model: Awareness, Desire, Knowledge, Ability, Reinforcement. | [Module 6](06-building-an-ai-ready-organization.md) |
| **AI agent** | A system that uses an LLM to take multi-step actions toward a goal, not just generate text. | [Module 2](02-how-generative-ai-works.md) |
| **AI champion** | An early-adopter employee who models AI use and supports peers. | [Module 6](06-building-an-ai-ready-organization.md) |
| **AI Center of Excellence (CoE)** | Cross-functional team setting AI standards and vetting use cases org-wide. | [Module 6](06-building-an-ai-ready-organization.md) |
| **AI opportunity canvas** | One-page template mapping a use case to value, capability, risk, and owner. | [Module 8](08-creating-an-ai-strategy.md) |
| **AI readiness** | Organizational preparedness across technology, data, people, and culture. | [Module 6](06-building-an-ai-ready-organization.md) |
| **AI-native competitor** | A company built from the ground up around AI-driven processes. | [Module 7](07-ai-enabled-economy.md) |
| **Augmentation vs. replacement** | AI assisting a human (augmentation) vs. performing the task with no human (replacement). | [Module 7](07-ai-enabled-economy.md) |
| **Bias (AI)** | Systematic skew in model output, usually from training data, labeling, or objective design. | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **CAIO (Chief AI Officer)** | Executive owning AI strategy, adoption, and risk org-wide. | [Module 6](06-building-an-ai-ready-organization.md) |
| **CDO (Chief Data Officer)** | Executive owning data quality, governance, and accessibility. | [Module 6](06-building-an-ai-ready-organization.md) |
| **Chain-of-thought prompting** | Asking a model to reason step-by-step before answering. | [Module 3](03-prompt-engineering.md) |
| **Context window** | The maximum text (input + output) a model can process at once, in tokens. | [Module 2](02-how-generative-ai-works.md) |
| **Data sovereignty** | The principle that data is subject to the laws of the jurisdiction where it's held. | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **Deepfake** | Synthetic audio/video/image convincingly depicting a real person doing/saying something false. | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **Effort-impact-risk matrix** | Framework plotting initiatives to find quick wins vs. strategic bets vs. items to defer. | [Module 8](08-creating-an-ai-strategy.md) |
| **EU AI Act** | EU regulation tiering AI obligations by risk level (unacceptable/high/limited/minimal). | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **Explainability** | The ability to describe, in human terms, why a model produced a given output. | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **Few-shot prompting** | Giving a model worked examples of the input→output pattern before the real request. | [Module 3](03-prompt-engineering.md) |
| **Generative AI** | AI that creates new content (text, image, audio, code) rather than only classifying/predicting. | [Module 1](01-understanding-ai-and-business-impact.md) |
| **Hallucination** | A confident but factually wrong or fabricated model output. | [Module 2](02-how-generative-ai-works.md) |
| **Kotter's 8-Step Change Model** | Org-wide change sequence: urgency → coalition → vision → enlist → remove barriers → wins → sustain → institute. | [Module 6](06-building-an-ai-ready-organization.md) |
| **Large language model (LLM)** | A model trained to predict likely next text, which at scale enables broad language tasks. | [Module 2](02-how-generative-ai-works.md) |
| **LLMOps** | Operational practices for deploying, monitoring, and maintaining LLM-based systems in production. | [Module 8](08-creating-an-ai-strategy.md) (referenced program-wide) |
| **Machine learning (ML)** | Models that learn statistical patterns from data instead of following hand-written rules. | [Module 1](01-understanding-ai-and-business-impact.md) |
| **Multimodal AI** | Models that accept and/or generate more than one content type (text, image, audio, code). | [Module 2](02-how-generative-ai-works.md) |
| **NIST AI Risk Management Framework** | Vendor-neutral risk framework: Govern, Map, Measure, Manage. | [Module 5](05-ethics-governance-and-responsible-ai.md) |
| **Prompt engineering** | Designing instructions to reliably get high-quality output from an AI model. | [Module 3](03-prompt-engineering.md) |
| **Prompt template** | A reusable prompt with placeholders, applied consistently across many instances. | [Module 3](03-prompt-engineering.md) |
| **Psychological safety** | A climate where raising concerns or admitting uncertainty isn't punished. | [Module 6](06-building-an-ai-ready-organization.md) |
| **RAG (Retrieval-Augmented Generation)** | Grounding an LLM's answer in retrieved, real source documents before generating. | [Module 2](02-how-generative-ai-works.md) |
| **Rule-based system** | Software following explicit, human-written logic rather than learned patterns. | [Module 1](01-understanding-ai-and-business-impact.md) |
| **Role prompting** | Assigning the model a persona/expertise frame to shift tone and priorities. | [Module 3](03-prompt-engineering.md) |
| **Token** | A unit of text (~¾ of an English word) that LLMs process and are billed by. | [Module 2](02-how-generative-ai-works.md) |
| **Zero-shot prompting** | Asking a model to perform a task with no worked examples given. | [Module 3](03-prompt-engineering.md) |

## How to use this glossary

- Studying for a specific module → read the module file directly; it has full context and examples.
- Reviewing before a meeting or the capstone → skim this table for the term, then jump to the linked section only if you need the example.
- Building your own organization's AI policy or capstone → this table doubles as a checklist of concepts to make sure your document actually addresses ([Module 5](05-ethics-governance-and-responsible-ai.md) and [Module 8](08-creating-an-ai-strategy.md) especially benefit from this).
