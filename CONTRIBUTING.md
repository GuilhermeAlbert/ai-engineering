# Contributing

Corrections, clearer explanations, practical examples, exercises, and primary sources are welcome.

Before opening a pull request:

1. read [WRITING.md](./WRITING.md)
2. keep both language editions in parity
3. preserve the order in both `SUMMARY.md` files
4. run `node scripts/check-book.mjs`
5. run `node scripts/check-book.mjs --edition pt-BR --parity-with .`
6. run `node --test scripts/*.test.mjs`

Changes to technical or time-sensitive claims should include a source.
