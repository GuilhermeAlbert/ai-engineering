# Glossary

**Agent:** A system in which a model selects and invokes tools across multiple steps toward a goal.

**Context window:** The bounded amount of input and prior output available to a model for one generation.

**Embedding:** A numeric representation that places semantically related items near one another in a vector space.

**Evaluation:** A repeatable method for measuring system quality, safety, cost, and latency against representative cases.

**Foundation model:** A broadly trained model that can be adapted to many downstream tasks.

**Generative AI:** Systems that produce new text, images, audio, video, code, or other structured outputs from learned patterns.

**Hallucination:** A plausible-looking output that is unsupported, incorrect, or invented.

**Inference:** Running a trained model to generate an output.

**Large language model (LLM):** A language model trained at large scale to predict tokens and perform a broad range of language tasks.

**LLMOps:** Practices for versioning, evaluating, deploying, observing, and improving systems built around language models.

**Multimodal model:** A model that accepts or generates more than one modality, such as text, image, audio, or video.

**Prompt:** The instructions, context, examples, data, and output contract supplied to a model.

**RAG:** Retrieval-augmented generation, a pattern that retrieves relevant material and includes it in model context before generation.

**Token:** A unit of text processed by a language model. Tokens are not identical to words.
